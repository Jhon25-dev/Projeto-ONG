# ONG Conecta Futuro

Projeto acadêmico de uma ONG fictícia voltada para inclusão digital e
educação tecnológica.

## Sobre o projeto

A Conecta Futuro apresenta projetos de inclusão digital, permite o cadastro
de voluntários e possui navegação entre diferentes páginas da aplicação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- LocalStorage
- Git
- GitHub

## Pré-requisitos

Para executar o projeto é necessário:

- Ter um navegador atualizado;
- Ter o Visual Studio Code ou outro editor de código;
- Ter o Git instalado, caso seja necessário trabalhar com o repositório
  localmente.

## Instalação local

1. Clonar o repositório:

   git clone URL_DO_REPOSITORIO

2. Entrar na pasta do projeto:

   cd "Projeto ONG"

3. Abrir a pasta no Visual Studio Code.

4. Executar o projeto utilizando um servidor local, como a extensão
   Live Server.

## Execução

Após iniciar o servidor local, acessar a página inicial do projeto pelo
navegador.

## Funcionalidades

- Apresentação da ONG;
- Exibição dos projetos;
- Cadastro de voluntários;
- Validação dos campos do formulário;
- Armazenamento dos voluntários utilizando LocalStorage;
- Navegação entre as páginas.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

Foi utilizado o padrão GitFlow, com a branch `develop` para desenvolvimento,
branches `feature/*` para novas funcionalidades e `main` para a versão
estável.

As mensagens de commit seguem o padrão Conventional Commits, utilizando
prefixos como `feat:` e `docs:`.

O versionamento das releases segue o padrão SemVer:

MAJOR.MINOR.PATCH

A primeira versão estável do projeto é representada por `v1.0.0`.

## Pull Requests

As alterações desenvolvidas em branches de funcionalidades podem ser
integradas à `develop` por meio de Pull Requests, permitindo documentar e
revisar as alterações antes do merge.

## Testes

A validação do projeto é realizada por meio dos testes funcionais das
páginas, formulários, navegação e armazenamento dos dados no navegador.
